# Heart-Disease-Feature-Separated (UCI) — Reproducible Code & Data

This repository contains the processed UCI Heart Disease dataset and Python scripts to reproduce the experiments reported in the paper, including the primary 80/20 hold-out results (Table 3), repeated hold-out stability statistics, additional split-ratio stability checks, and leakage-safe stratified 10-fold cross-validation.

---

## Requirements

* Python 3.9+ recommended
* Common packages used in this project:

  * `numpy`, `pandas`, `scikit-learn`
  * `torch` (if the Channel-2 DNN uses PyTorch)
  * `xgboost` (for XGBoost)
  * `matplotlib` (optional, if any plots are enabled)

### Quick install

```bash
pip install -r requirements.txt
```

If you do not have a `requirements.txt`, install the core dependencies manually:

```bash
pip install numpy pandas scikit-learn xgboost torch matplotlib
```

## Data

The `data/` directory contains the **processed (derived)** UCI Heart Disease dataset used in the experiments (cleaned + imputed + standardized-ready tables, and labels).

* The original raw dataset is publicly available from the **UCI Machine Learning Repository**.
* This repository provides the processed version used in our pipeline to ensure consistent reproduction of results.

## How to Reproduce the Paper Results

### 1) Primary result used in Table 3 (single 80/20 hold-out)

**Script:** `B6.py`
**Purpose:** Runs the main 80/20 hold-out protocol and outputs the metrics reported for the proposed model in **Table 3**.

**Run:**

```bash
python B6.py
```

**Expected output:**

* Accuracy, Precision, Recall, F1-score, AUC for the single 80/20 split
* This is the **primary comparative point estimate** used in Table 3.

---

### 2) Robustness: repeated stratified 80/20 hold-out statistics (mean ± std + 95% CI)

**Script:** `B6_repeated_holdout_stats.py`
**Purpose:** Evaluates **result stability beyond a single split** using repeated stratified 80/20 hold-out runs across multiple random seeds.

**Run:**

```bash
python B6_repeated_holdout_stats.py
```

**Expected output:**

* Per-repeat metrics (ACC, P, R, F1, AUC)
* Summary table:

  * mean ± std
  * 95% confidence interval for the mean (t-distribution)
* Used to support the **Statistical Analysis / Robustness** subsection in the manuscript.

---

### 3) Robustness: additional split ratios (70/30 and 90/10) stability table

**Script:** `B6_splitratio_stability.py`
**Purpose:** Runs repeated stratified evaluations for **two additional split ratios** and prints a compact “tiny stability table”.

**Run:**

```bash
python B6_splitratio_stability.py
```

**Expected output:**

* Summary tables (mean ± std + 95% CI) for:

  * 70/30 split
  * 90/10 split
* A compact table reporting key metrics for each split ratio.
* Supports the robustness narrative without changing the main Table 3 comparison protocol.

---

### 4) Leakage-safe stratified 10-fold cross-validation (OOF fusion training)

**Script:** `B6_option2_cv.py`
**Purpose:** Implements a **leakage-safe** stratified 10-fold CV evaluation.
The fusion model is trained on **out-of-fold (OOF)** base-model probabilities generated by an inner CV loop, ensuring the fusion layer never sees in-sample base predictions.

**Run:**

```bash
python B6_option2_cv.py
```

**Expected output:**

* Fold-by-fold metrics and an overall CV summary for ACC, P, R, F1, AUC
* Reported in the manuscript as a **robustness check** (not used in Table 3 to preserve fair comparability with prior works).

## Reproducibility Notes

* The **primary comparison** in Table 3 uses a single **80/20 hold-out** evaluation to align with common reporting practices in prior UCI heart-disease studies.
* Additional evaluations (repeated hold-out, alternate split ratios, 10-fold CV) are reported as **robustness/stability analyses**.
* When applicable, trainable preprocessing steps and model fitting are performed using **training data only** within each split/fold.
